10 — Philosophy

Design Principles

The constraints that give MoonFrame its character. Hover to feel the lift.

01

Concepts Before Code

Don't touch a single line without understanding the why. Every component in MoonFrame traces back to a clear mental model — slot machine, cinema ticket, firefly glow.

02

Cinema, Not Software

Every interaction should feel like a scene — the reel spinning, the card dropping, the stars catching light. UI that performs, not just functions.

03

Nocturnal & Immersive

Dark skies, firefly accents, and crescent moons. The palette evokes a dusk landscape — you're not using an app, you're watching a film under the stars.

04

Solid Foundations First

Tokens before components, components before pages. The design system is the source of truth — nothing ships that isn't anchored to a CSS variable.
